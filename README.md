# The Daily Ledger

A static newspaper-style web app designed for a clean black, white, and grey editorial experience. The page includes front-page story layouts, section navigation, newsletter signup UI, and multiple Google AdSense-ready advertising slots.

## Files

- `index.html` - page structure and editorial content
- `styles.css` - responsive newspaper design system
- `script.js` - current date, reading progress, category highlighting, and signup feedback

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## AdSense setup

The ad spaces are marked with `.ad-slot` elements and `data-ad-format` attributes. After your Google AdSense account is approved:

1. Add the AdSense loader script from your Google AdSense dashboard to the `<head>`.
2. Replace each placeholder inside `.ad-slot` with the ad unit code generated by Google.
3. Keep ad placements compliant with Google policies and avoid placing ads where users may click accidentally.
